Conditional Coupons & Memory

A headline coupon rate is not necessarily an amount owed. Follow each observation to see whether income is paid, lost forever or carried in a memory balance.

Observation ledger

The current coupon is tested first; memory catch-up is then calculated; finally the automatic-call test is applied.

Date Underlying Coupon test Coupon paid Memory balance Call test

Fixed

Every scheduled coupon is paid while the note remains outstanding, independent of the observed underlying level.

Conditional

A failed observation means that period’s coupon is lost. A later recovery does not repair it.

Memory

A failed coupon is banked. If a later coupon test passes, the current coupon and accumulated eligible coupons are paid together.

Mechanics references

The memory convention modeled here follows examples where a passing coupon observation pays both the current coupon and previously unpaid coupons, including on an automatic-call date when the coupon test also passes. See this SEC-filed memory-coupon autocall. The delivery-unit convention follows an SEC-filed physical-delivery example. Exact ordering and settlement terms remain product-specific.
